# Tama

Tama — нативная утилита для macOS с котом Sterling на рабочем столе. Приложение развивается как визуальный интерфейс для мониторинга состояния Mac.

Требования продукта описаны в [`docs/PRODUCT_SPEC.md`](docs/PRODUCT_SPEC.md).

## Требования

- Apple Silicon Mac;
- macOS 15 или новее;
- Xcode со Swift 6.2 или новее.

## Сборка и запуск

```sh
swift build
swift run Tama
```

## Проверки

```sh
swift test
swift run TamaChecks
```
